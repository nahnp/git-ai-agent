# Changelog

Este projeto segue [Conventional Commits](https://www.conventionalcommits.org/) e [Semantic Versioning](https://semver.org/).

## [Unreleased]

### feat
- Protótipo executável CLI + MCP com leitura Git, review local, scanner de segredos, checks configuráveis, relatórios estruturados, Conventional Commit e sessões fail-safe para commit e push separado.

### test
- Testes unitários e integração com repositórios Git reais, incluindo alteração pós-preparação, segredo, check falho e remote local.

### security
- Validação de raízes permitidas, subprocessos sem shell e com timeout, limite de diff, redação de segredos e ausência de force-push.

### docs
- Criação completa da documentação inicial do projeto: `CLAUDE.md`, `PROJECT_SPEC.md`, `ARCHITECTURE.md`, `TASKS.md`, `ROADMAP.md`, `DECISIONS.md`, `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`, `LICENSE`.
- Criação do esqueleto de diretórios: `docs/`, `examples/`, `.github/`, `.devcontainer/`, `.claude/`, `config/`.
